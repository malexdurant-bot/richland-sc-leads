# Richland County SC — Lead Intelligence Dashboard

Client-facing lead dashboard for Richland County, South Carolina. Served via
GitHub Pages at [richlandsc.justfriday.ai](https://richlandsc.justfriday.ai).

This repo contains only the built static dashboard and its current data
snapshot (`data/leads.json`) — no scraper source code. Data is refreshed
automatically by the production pipeline in a separate private-facing repo.
